# Tripwise-travel-planner
A responsive travel planning website built using HTML,CSS, JAVASCRIPT and Wikimedia APIs
TripWise – Smart Travel Planner

Project Overview

TripWise is a responsive travel-planning website that helps users discover destinations, explore tourist attractions, and organise places they want to visit.

The application retrieves destination information and available photographs from Wikipedia and Wikimedia Commons APIs.

Track

Track 1 – Frontend Development

AWS Student Builder Group Recruitment, VIT Chennai.

Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactivity and API integration
- Wikipedia API – Destination information and descriptions
- Wikimedia Commons API – Destination photographs
- LocalStorage – Saving selected destinations

Features

- Explore featured travel destinations.
- Search for tourist attractions in different cities.
- View destination details and available photographs.
- Add destinations to My Trip.
- View and remove saved destinations.
- Preserve saved destinations after refreshing the page.
- Responsive layout for desktop and mobile.
- Display feedback when destination information is unavailable.

API Integration

TripWise uses Wikipedia and Wikimedia Commons to retrieve destination information and available images dynamically.

Basic public API requests do not require an API key. Image availability depends on Wikimedia's data.

How to Run

1. Clone or download this GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension.
4. Search for destinations and explore the available attractions.
